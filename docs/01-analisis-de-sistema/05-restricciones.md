# 05. Restricciones del Sistema - Hampi Ayacucho

| ID | Restricción | Descripción |
| :--- | :--- | :--- |
| **RC01** | **Plataforma Exclusivamente Web** | Todo el sistema opera a través de un navegador web, descartando aplicaciones móviles nativas. |
| **RC02** | **Control de Versiones** | El proyecto debe versionarse obligatoriamente usando Git y GitHub con Conventional Commits. |
| **RC03** | **API REST** | El frontend web y el backend se comunican exclusivamente mediante el estándar API REST. |
| **RC04** | **Plataforma PIDE** | La validación de DNI debe integrarse con los servicios de RENIEC a través de la PIDE del Estado peruano. |
| **RC05** | **Estándar RENHICE** | La exportación de datos de salud debe ajustarse a las normas técnicas del MINSA para interoperar con el RENHICE. |
| **RC06** | **Marco Legal** | Cumplimiento obligatorio de la Ley de Protección de Datos Personales (Ley 29733) y Ley General de Salud (Ley 26842). |
