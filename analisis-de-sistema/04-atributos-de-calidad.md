# 04. Atributos de Calidad - Hampi Ayacucho

| ID | Atributo | Escenario de Calidad |
| :--- | :--- | :--- |
| **AC01** | **Rendimiento** | Soportar 5,000 usuarios concurrentes respondiendo el 95% de consultas de citas en menos de 2 segundos. |
| **AC02** | **Disponibilidad** | Mantener un 99.9% de disponibilidad operativa continua (24/7) para emergencias y consultas médicas. |
| **AC03** | **Escalabilidad** | Escalar de 5,000 a 15,000 usuarios concurrentes ante picos de apertura de citas o campañas de salud. |
| **AC04** | **Seguridad** | Cifrado de datos en tránsito (HTTPS) y en reposo (AES-256), protegiendo la confidencialidad médica (Ley N.° 29733 y Ley N.° 26842). |
| **AC05** | **Accesibilidad** | Interfaz web accesible (WCAG 2.1 AA) con soporte bilingüe en español y quechua. |
| **AC06** | **Mantenibilidad** | Arquitectura desacoplada en capas para facilitar futuras integraciones normativas con MINSA. |
