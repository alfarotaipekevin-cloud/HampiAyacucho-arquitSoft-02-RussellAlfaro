# 03. Requisitos Funcionales - Hampi Ayacucho

## Requisitos Funcionales
- **RF01:** Consultar disponibilidad de citas médicas por establecimiento y especialidad en tiempo real.
- **RF02:** Reservar citas médicas mediante el portal web validando identidad ciudadana.
- **RF03:** Generar y descargar ficha digital con código QR para el ingreso a la cita.
- **RF04:** Registrar y consultar antecedentes, diagnósticos y tratamientos en la Historia Clínica Electrónica (HCE).
- **RF05:** Emitir solicitudes de referencia digital entre establecimientos de la red de salud.
- **RF06:** Gestionar la admisión, derivación y turno de contrarreferencias en establecimientos receptores.
- **RF07:** Proporcionar dashboard en tiempo real con tiempos de espera y ocupación de consultorios.
- **RF08:** Emitir reportes de indicadores epidemiológicos y de atención bajo formato MINSA.
- **RF09:** Implementar autenticación de doble factor (2FA) y auditoría de accesos a datos sensibles.

## Trazabilidad con Historias de Usuario
- HU01 → RF01
- HU02 → RF02, RF03
- HU03 → RF04
- HU04 → RF05
- HU05 → RF06
- HU06 → RF07
- HU07 → RF08
- HU08 → RF09
