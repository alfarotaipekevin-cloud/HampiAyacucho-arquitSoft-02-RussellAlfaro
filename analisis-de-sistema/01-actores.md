# 01. Actores del Sistema - Hampi Ayacucho

## 1. Actores Humanos
| Actor | Descripción y Necesidades |
| :--- | :--- |
| **Paciente** | Consulta disponibilidad de citas en tiempo real, reserva turnos web y obtiene su ficha digital con código QR. |
| **Personal de Salud** | Médicos y administrativos que registran atenciones clínicas y generan referencias digitales hacia hospitales. |
| **Especialista GERESA** | Supervisa la red asistencial, analiza tiempos de espera y elabora reportes normativos para el MINSA. |
| **Administrador** | Gestiona accesos, seguridad con doble factor (2FA) y auditoría del sistema. |

## 2. Sistemas Externos
| Sistema Externo | Responsabilidad |
| :--- | :--- |
| **RENHICE (MINSA)** | Registro Nacional de Historias Clínicas Electrónicas para intercambio de datos de salud a nivel nacional. |
| **PIDE (RENIEC)** | Plataforma de Interoperabilidad del Estado para validar la identidad y el DNI de los usuarios. |
| **Servicio de Mensajería** | Envío de notificaciones y confirmaciones por SMS y correo electrónico. |
